# Ogbifọ — User Stories

## Reading

- **US-001** As a learner, I want to receive a language card so that I can encounter authentic language.
- **US-002** As a learner, I want to see the original text before its translation so that I engage with the language itself.
- **US-003** As a learner, I want to hear/read a phrase at my own cadence so that practice feels natural.
- **US-004** As a learner, I want to receive a Resonance Score so that I can understand areas for improvement.

## Translation

- **US-005** As a user, I want to translate text between supported languages.
- **US-006** As a user, I want to swap source and target languages.
- **US-007** As a user, I want the original orthography preserved.

## Contribution

- **US-008** As a native speaker, I want to contribute a phrase.
- **US-009** As a contributor, I want to attach dialect and context.
- **US-010** As a contributor, I want my contribution saved even if I lose connectivity.
- **US-011** As a community member, I want to confirm accurate contributions.
- **US-012** As a contributor, I want to see whether my contribution is pending or verified.

## Discovery

- **US-013** As a learner, I want to browse language decks.
- **US-014** As a curious user, I want to discover languages and regions.
- **US-015** As a researcher, I want to identify archive gaps.

## Progression

- **US-016** As a learner, I want to track progress.
- **US-017** As a contributor, I want recognition for preserving language material.
- **US-018** As a user, I want to unlock additional content through meaningful participation.
